# GlucoBar

A simple macOS menu bar app to monitor your blood glucose in real-time using LibreLink Up or Nightscout.

## What It Does

Shows your current glucose reading and trend directly in your menu bar. That's it.

## Features

- Real-time glucose reading in the menu bar
- Status indicator showing connection state and data freshness
- Historical glucose graph (customizable 1-24 hour window)
- Custom glucose targets
- Support for mg/dL and mmol/L units
- Support for both LibreLink Up and Nightscout data sources
- Secure credential storage via Keychain

## Quick Start

**Option 1: Download a Release**
1. Go to the [Releases](../../releases) tab
2. Download the latest `.dmg` file
3. Drag GlucoBar to your Applications folder
4. Run and enter your credentials

**Option 2: Build from Source**
1. Clone this repository
2. Open `GlucoBar.xcodeproj` in Xcode
3. Build and run

## Requirements

- macOS 15.0 or later
- LibreLink Up account or Nightscout instance
